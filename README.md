# IGIS Development Project Platform

개발사업의 사업비·계약·인허가·개발업 등록정보를 관리하고 국토교통부 보고서를 작성하는 사내 업무 플랫폼입니다.

현재는 로컬 HTML 검증본입니다. 중앙 데이터베이스·직원 로그인·운영 배포가 완료된 서비스는 아닙니다.

## 현재 버전과 운영 상태

기준일: 2026-10-14. 제품 검증과 클라우드 준비는 별도 상태로 관리합니다.

| 구분 | 현재 상태 |
|---|---|
| 제품 버전 | v0.10.33 — 로컬 검증본 |
| 저장 방식 | 브라우저별 로컬 저장. 중앙 데이터베이스 미연결 |
| 자동검사 | 최종 소스 129 개 검사군 모두 통과, 검사 중 소스 변경 없음 |

| GitHub | 전용 비공개 저장소. README·버전 이력·변경 내역으로 기록을 관리하며 제품 코드는 미게시 |

기존 서비스의 중지·삭제·유료 전환은 하지 않았습니다. 클라우드 자원 생성이나 Vercel 보호 설정은 앱의 직원 로그인·서버 권한·데이터 저장·운영 배포 완료를 의미하지 않습니다. Vercel 의 현재 Hobby 요금제는 개인 비상업용이므로 회사 운영 배포는 요금제 승인 전 진행하지 않습니다. 유료 구독 승인은 아직 없습니다. [Vercel Hobby 공식 기준](https://vercel.com/docs/plans/hobby)

Supabase 의 무료 프로젝트 한도는 소유자/관리자 권한이 있는 전체 조직 합계 기준입니다. 다른 조직으로 옮기거나 기존 서비스를 중지해 한도를 우회하지 않습니다. [Supabase 요금·무료 프로젝트 한도](https://supabase.com/docs/guides/platform/billing-on-supabase)

## 주요 기능

| 업무 | 현재 검증본의 기능 |
|---|---|
| 프로젝트 현황 | 일반 진입은 홈으로 시작하고, 주 메뉴 클릭은 첫 세부탭으로 이동 |
| 세부 사업비 | 회사 공통 관리항목, 분류 접기·펼치기, 같은 셀 더블클릭 편집, 행 이동·삭제·이력 |
| 항목 선택·추가 | 분류별 탐색·검색. 이미 포함된 항목은 후보에서 제외하고 금액은 임의 생성하지 않음 |
| 비용 코드·분석 | 표준 비용유형과 실제 기록을 구별하여 연결. 기존 미확정 분류를 정상 비용으로 추측하지 않음 |
| 사업비 엑셀 | 화면의 실제 분류명·항목명·순서로 한 시트만 내려받기 |
| 계약·문서 | 한 목록에서 조회·추가·수정·삭제, 원본 경로 확인·복사 |
| 인허가·심의 | 필수 일정·근거문서 경로, 검토의견별 조치계획, 입력 오류와 이전 팝업 복귀 |
| 개발업 등록 | 담당팀이 등록 상태 입력. 등록정보와 전문인력 명단을 공통 팝업 서식으로 입력 |
| 국토부 보고서 | 양식의 모든 셀 편집, 보고서에만 저장 또는 명확히 연결된 플랫폼 값에도 반영 선택 |
| 변경 보호 | 미저장 경고·초안 보관·재열기, 저장 실패와 충돌 때 값 보존, 과거 확정본·저장 보고서 보호 |

사업비는 원 단위 정수로 저장하고 표에서는 정수 백만원으로 표시합니다. 미입력과 확인된 0 원은 다르게 취급합니다. 회사 관리표에 CBS 의 누락·중복 검토 개념을 보완한 체계이며, 법정 또는 국제 표준 자체라고 주장하지 않습니다.
