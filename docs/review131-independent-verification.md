# REVIEW131 독립 검수

현재는 구현 중간 소스의 집중검사 단계입니다. 정식 C92의 기존 266그룹·법령 재개 검수는 [당시 실제 근거](review130-c92-live-verification.json)이며 이번 변경의 통과 수로 더하지 않습니다. 제품 수정·실제 DB·외부 업무 API·브라우저는 이 검토자가 실행하지 않았습니다.

## 독립 기대값

- 교통영향평가는 지정된 도시교통정비지역·교통권역과 대상사업·건축물 범위가 결합된 조건입니다. 지역 이름이나 면적 하나로 대상을 확정하지 않습니다. 지역 조례와 예외도 남습니다. [도시교통정비 촉진법 제15조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1011819121)
- 특수구조 건축물의 구조 안전에 관한 지방건축위원회 심의는 일반 구조안전 확인·굴토 심의와 구별합니다. 기존 유형을 연결하며 의제·공동심의·특례를 별도로 확인합니다. [시행령 제5조의5](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1028913615), [제6조의3](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=03&joNo=0006&lsiSeq=290833&urlMode=lsScJoRltInfoR)
- 군사기지·군사시설 보호구역 경로와 대공방어협조구역 경로를 분리합니다. 후자는 구역과 법정 높이를 함께 확인하며, 절대 건물 높이·서울 주소로 부대별 수평조준선 기준을 만들어내지 않습니다. 기존 보호구역 경로는 OR 조건으로 보존합니다. 실무 약칭은 검색과 기록 동일성을 구별합니다. [법 제13조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1029623069), [시행령 제13조](https://www.law.go.kr/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=1003646731)

`candidate`는 검토 후보이며 법적 의무·인가 완료가 아닙니다. 조건의 미확인과 명시적 아니오는 별도로 대조합니다. 속성 부재만 최초 기본정보를 사용하고 저장된 null·공란·0은 되살리거나 만들지 않습니다.

## 원본과 분모

Cost Tracker 1시트와 마스터플랜 21시트(숨김 1개)의 목록 및 인허가 관련 표제만 새로 읽었습니다. 관련 XML을 파싱했지만 모든 내용·수식·금액·일정을 다시 검수한 것은 아닙니다. 원본 두 파일의 지문은 전후 동일하며 재계산·재저장하지 않았습니다. 원문 표제와 사업 값은 비공개 `.build/review131/independent/`에만 보관합니다.

카탈로그 보존 검사는 현재 구현 배열이 아니라 지문을 고정한 기존 60행 근거자료의 ID를 기준으로 합니다. 60개 관리유형, 신규선택 58개, 과거 복합 2개를 구별합니다. 과거의 추천도달 34/수동 24와 새 조건 반영 후의 도달 수는 버전별 관측이며 법적 완결성의 증명이 아닙니다. 수동 선택 항목을 카탈로그 누락이라고 세지 않습니다.

## 현재 실행

기계판독 가능한 정확한 소스·시험·결과 지문은 [검수 JSON](review131-independent-verification.json)에 둡니다. 동시 구현 중인 서로 다른 집중검사 결과를 하나의 최종 소스 통과로 합치지 않습니다.

| 검사 | 범위 | 현재 판정 |
|---|---|---|
| 독립 조건 모델 | 세 판단군의 AND/OR·미확인/아니오, 명시적 null/공란/0, 실제 UI 조건 소비자 | 261조건 통과, 실제 화면 0 |
| 실제 workspace handler 모델 | 실제 runtime·PUT/GET·공통 검증·CAS와 모형 SQL 거래, 조건 단독/일괄·422·503·403·409·재조회·재시도 | 15조건 통과, 실제 DB 0 |
| 카탈로그·명칭 | 기존 ID·복합 제외·공식 절차 의미·명시된 옛 정식명·검색 약칭·기록 보존 | 중간 결과를 JSON에 기록, 최종 소스 재실행 대기 |
| 단일 intake·사업개요 수정 단위 | 실제 등록된 폼/콜백·취소·실패·탭·프로젝트 및 면적 소비자 | 독립 검사 준비/진행 중 |
| 실제 화면·저장·재접속·배포 | root 담당 정확 후보·승인 가상사업 | 이 검토자 미실행 |

첫 카탈로그 검사에서 VM 배열과 호스트 배열의 prototype 차이가 2조건을 막았습니다. 값·ID·순서 기대는 유지하고 호스트 배열로 읽어 준비만 바로잡았습니다. 이를 제품의 ID 누락으로 보고하지 않습니다.

## 남은 의미 점검

물류 섹터 하나가 물류단지·물류터미널 개발을 뜻하지 않으며, 주거 용도만으로 주택사업계획 승인·입주자모집을 일괄 의무로 볼 수 없습니다. 관련 사업종류·규모와 적용범위를 확인해야 합니다. [물류시설법 제2조](https://www.law.go.kr/LSW/lsInfoP.do?ancYnChk=0&chrClsCd=010202&efYd=20260102&lsiSeq=276991&urlMode=lsInfoP)

주택법 사업계획 승인 경로의 사용검사는 건축법 사용승인과 근거·명칭을 자동으로 같게 취급하지 않습니다. 현재 60유형의 대체·의제 경로와 회사 관리단위를 추가 확인할 대상으로 기록하며, 이 조사만으로 새 유형이나 규모 조건을 구현하지 않습니다. [주택법 제49조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1033856207). 일부 한글 법령 링크가 미래 시행 본문으로 연결돼 현재 조문으로 쓰지 않았습니다.

## 실제 화면에 남길 유한 검사

같은 팝업의 두 탭, 자동 추천과 수동 체크/해제, 조건만 저장과 선택 항목 일괄 저장, 명시적 지움 재진입, 이미 포함된 ID/옛 정식명, 검색 약칭과 동일성 분리, 저장 실패의 원입력·부모·위치 보존, 제공된 취소 선택, 열린 뒤 권한/자료/사업 변경, 새 GET·재접속을 연결합니다. 숫자/날짜 입력과 마지막 CTA의 도달·가림·폭은 root 실제 화면에서 별도 확인해야 합니다. 계획·모형 콜백·실제 UI·DB·배포를 서로 통과로 승계하지 않습니다.
