## 보존 경계와 실패 검사

운영 DB/원본 저장소는 읽기 전용. 로컬 저장자료, 부지·토지계약 4열과 전체 지급회차 팝업(259), 원가·파이낸싱·Feed·다른 화면은 보존한다. 새 계약·문서 탭은 범위 밖이다. 미등록/삭제/사업변경/권한변경 대상은 저장을 차단하며 새 행으로 바꾸지 않는다. 편집 오류는 입력을 유지하고 취소/X/Escape는 실제 부모로 복귀한다.

기능 이식 전 새 검토의견 저장 API/추적필드, 전문인력 상세 진입이 없음을 실패검사로 확인한다. 구현 후 격리 자료로 추가/수정/보존·잘못된 값·프로젝트 문맥을 검사하고 실제 로컬 네 탭의 진입·팝업·스크롤을 확인한다. 최신 자료 캡처와 공유 패키지 빌드/검증 후 커밋만 한다.
