# 사업지 지역조례 확인 근거

확인일: 2026-10-20 · 연결 요구: CENTER120-07 · 구조화 근거: [동명 JSON](center-20261020-regional-law-review.json)

이 문서는 공식 자료를 읽어 정리한 **구현 참고 근거**입니다. 지역별 적용조건의 자동판정, 전국 조례 전수 확인, 제품 구현·실제 화면 검수 완료를 뜻하지 않습니다. 회사 사업·비밀설정·외부 서비스·DB를 변경하지 않았습니다.

## 1. 확인 결과

- 사업지의 광역·기초 관할을 확인하고, 해당 지역에서 **확인할 조례 후보·제정기관·적용조건을 확인할 부분**을 보여주는 흐름이 필요합니다. 검색창이나 원문 링크의 존재만으로 이 요구를 완료 처리하지 않습니다.
- 조례 제정기관, 인허가 처리기관, 심의위원회는 서로 다를 수 있습니다. 광역 조례를 근거로 자치구가 실제 공람·접수를 수행한 2026년 서초구 공식 공고 사례도 확인했습니다. [서초구 공고 제2026-601호](https://eminwon.seocho.go.kr/emwp/gov/mogaha/ntis/web/ofr/action/OfrAction.do?context=NTIS&jndinm=OfrNotAncmtEJB&method=selectOfrNotAncmt&methodnm=selectOfrNotAncmtRegst&not_ancmt_mgt_no=43947&subCheck=Y)
- **빈값·검색 0건·별표 미제공·관할 미확인 ≠ 비대상**입니다. 법정 요건, 지역 원문, 사업 사실을 대조하기 전에는 `확인 필요`입니다. 다른 지역의 수치나 과거 개정안의 수치를 기본값으로 넣지 않습니다.

## 2. 공식 조회 범위와 기관코드

| 공식 서비스 | 확인된 요청·의미 | 구현 시 지켜야 할 경계 |
|---|---|---|
| `target=ordin` | `org`는 광역, `sborg`는 기초 검색입니다. 공식 예시는 서울 `org=6110000`, 구로구 `org=6110000&sborg=3160000`입니다. | 기초 코드만 `org`에 넣지 않습니다. 광역·기초 코드를 각각 공식 기관명과 연결합니다. 예시 코드를 실제 사업 관할로 사용하지 않습니다. |
| 조례·규칙 종류 | 목록의 `knd=30001`은 조례, `30002`는 규칙입니다. 현행 `nw=1`, 연혁 `nw=2`이며 기본은 현행입니다. | 조례만 조회하고 시행규칙도 확인했다고 하지 않습니다. 현재 적용판과 과거 진행 당시 판본을 구분합니다. |
| 목록 페이지 | `display` 기본 20·최대 100, `page`가 있습니다. | 사용자 검색의 상위 20건과 관할 범위의 확인 완료를 구분합니다. 완전 수집을 주장할 때는 전체 페이지·요청 범위·실패를 기록합니다. |
| 법령별 연계 조례 | `target=lnkLsOrd`, `knd`에는 법령ID를 사용합니다. | 위임 관련 후보를 찾는 보조 근거입니다. 연계 결과만으로 모든 자치법규가 망라되었다거나 적용이 확정되었다고 하지 않습니다. |
| 지자체별 연계 목록 | `target=lnkOrg`의 `org`는 지자체 기관코드입니다. 공식 예시에 부산 동구의 기관코드가 있습니다. | `ordin`의 광역 `org`/기초 `sborg` 규칙과 혼동하지 않습니다. |
| 조례 본문·별표 | 본문은 자치법규ID/일련번호로 조회합니다. 공식 가이드는 별표 제공 범위를 서울시교육청·본청으로 제한한다고 밝힙니다. | 다른 기관의 별표가 응답에 없으면 공식 지자체 원문·공보·별표 파일 확인을 남깁니다. 별표 없음으로 자동 확정하지 않습니다. |

근거: [자치법규 목록 가이드](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=ordinListGuide), [법령·조례 연계 가이드](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=ordinLsConListGuide), [본문·별표 제공 범위](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=ordinInfoGuide).

이번 조사에서 전국 최신 기관코드표 전체를 확보·대조하지 않았습니다. 공식 코드의 광역·기초 계층과 유효기간을 확인할 기준자료가 필요하며, 자유입력 주소·법정동코드 등을 기관코드로 추측 변환하지 않습니다.

## 3. 분야별로 보여줄 후보와 확인 부분

아래는 지역조건 확인의 기본 범위이지, 모든 사업에 인허가를 추가할 목록이나 확정 의무 목록이 아닙니다.

| 분야 | 확인할 조례·규칙 후보 | 구분할 기관 | 사업에서 확인할 사실·원문 부분 | 자동으로 결론 내리면 안 되는 것 |
|---|---|---|---|---|
| 건축·구조·굴토 | 해당 관할의 건축 조례·시행규칙, 관련 공식 위원회 운영기준 | 조례 제정기관 / 허가권자 / 시·도 또는 시·군·구 위원회 | 용도·층수·높이·연면적·다중이용/특수구조 여부, 굴착깊이·주변시설, 심의 대상·예외·위원회 배분·부칙 | 자치구 위원회가 처리한다는 이유로 자치구 조례만 적용, 다른 지역의 굴토 수치 일괄 사용 |
| 도시계획·개발행위 | 관할 도시·군계획/도시계획 조례·시행규칙, 해당 필지의 지구단위계획·성장관리계획 등 공식 결정자료 | 계획 결정기관 / 개발행위 허가권자 / 심의위원회 | 용도지역·지구·구역, 토지 형질변경과 규모, 높이·경사·수목·배수·기반시설, 별표 허가기준·계획 제한·경과조치 | 지역명·전체 연면적만으로 개발행위허가 대상·허용 여부 확정, 조례 검색으로 필지별 결정고시까지 확인 완료 |
| 경관 | 관할 경관 조례·시행규칙·경관계획의 해당 부분 | 조례 제정기관 / 사업 승인기관 / 해당 경관·건축위원회 | **개발사업 제27조**와 **건축물 제28조**를 별개 검토. 경관지구·중점경관관리구역·공공건축 여부와 지역 규모·예외·변경 기준 | 개발사업 경관심의 비대상이면 건축물 경관심의도 비대상, 의제 건축허가이면 모든 경관검토 생략 |
| 환경영향평가 | 관할 환경영향평가 조례·시행규칙·대상사업 별표 | 조례 제정권자 / 협의기관 / 승인기관 / 의견수렴 수행기관 | 국가 평가와 지역 평가의 구분, 사업 종류·규모·입지·시행주체·예외, 도 조례 존재 여부, 제출시기·변경·재협의·부칙 | 광역·기초 조례가 모두 검색됐으므로 평가를 이중 생성, 국가평가와 지역평가를 이름만으로 같은 절차로 병합, 별표 누락을 비대상 처리 |

### 확인한 상위 근거

- 건축법 시행령 제5조의5의 공식 조회에서 지방건축위원회의 광역·기초 구분과 구조안전 심의 항목을 확인했습니다. 이번에 열린 조문 페이지는 **일부 항목 발췌**이므로 조문 전체·지역별 굴토 수치를 확인했다고 확대하지 않습니다. [시행 2026-10-06 조문 발췌](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1028913615)
- 국토계획법 제58조는 도시·군관리계획·성장관리계획, 주변환경·경관 및 기반시설 등을 허가기준으로 다룹니다. 따라서 조례명만으로 필지의 실제 제한까지 대체할 수 없습니다. [시행 2026-07-01 제58조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1032697693)
- 경관법 제28조는 지역 조례로 정하는 건축물을 다룹니다. 법제처 21-0351은 제27조 개발사업과 제28조 건축물의 심의 대상을 별개로 보아야 한다고 설명합니다. 해석례는 법원의 확정판결과 같은 지위로 취급하지 않습니다. [제28조](https://law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=1000307055), [법제처 21-0351](https://law.go.kr/expcInfoP.do?expcSeq=327203)
- 환경영향평가법 제42조는 일정 범위의 지역 평가를 규정합니다. 인구 50만 이상 시의 경우 관할 도에 해당 평가 조례가 없을 때에만 그 시 조례에 따라 실시할 수 있으므로 관할 계층을 함께 확인해야 합니다. [제42조](https://www.law.go.kr/lsLinkCommonInfo.do?ancYnChk=&chrClsCd=010202&lsJoLnkSeq=1028855407)

서울 사례는 근거 확인 방법의 사례입니다. 다른 지역 후보의 실제 존재·판본·수치·관할을 확인한 것으로 보지 않으며, 전국에 서울 기준을 적용하지 않습니다.

## 5. 읽기 전용 확인 흐름의 구현 기준

1. **사업지 확인:** 원문 주소와 광역·기초 기관명·코드·확인 출처를 보여줍니다. 불명확하면 관할 미확인으로 남기고 일반 검색은 가능하게 하되 지역 적용을 확정하지 않습니다.
2. **확인할 조례 후보:** 위 4분야의 후보, 관할, 공식 제목·판본·출처와 확인해야 할 조건을 함께 제시합니다. 명칭 검색과 상위법 연계 결과를 대조하며 단순 추천을 법적 필수로 바꾸지 않습니다.
3. **본문·별표·부칙 확인:** API 제공 범위와 확인하지 못한 부분을 구별합니다. 실패·빈 응답·일부 페이지·별표 미제공은 미확인입니다.
4. **사업 사실과 대조:** 적용조건의 원문과 사업의 규모·입지·행위·기준일을 나란히 확인할 수 있게 합니다. 법률 적용 최종판단은 담당 검토이며 조회만으로 진행 상태·승인일·인허가 원장을 자동 작성하지 않습니다.
5. **기존 인허가와 연결:** 기존 신청·보완·심의 회차, 검토의견·조치계획·증빙·이력은 그대로 둡니다. 관련 법령을 추가하거나 개정판이 발견되어도 과거 판단과 일정은 덮어쓰지 않습니다.

완료 판정은 `관할 확인`, `후보 조회`, `원문/별표 확인`, `사업 적용 검토`, `제품 구현`, `자동검사`, `실제 화면 검수`를 분리해야 합니다. 이 문서의 완료 범위는 **공식 근거 조사와 구현 경계 정리**입니다.
