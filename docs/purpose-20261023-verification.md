- 변경이 없는 검증 실패에도 복원하면서 강제중복 ID를 가진 두 임시 행이 서로 변하는 공통 오류를 교정했습니다. 실제 변경 후 실패의 기존 원복은 유지합니다. 정상 서버/초기 무결성 검사가 차단하는 강제 손상 상태의 추가 변경·복원 잔여위험은 정상 서비스 검수와 구분합니다.
- 사업비 검색어 입력 직후 이력 버튼 첫 클릭은 PC/390에서2회 실패했습니다. `pointerdown → input change → tbody 교체 → pointerup 대상 소실`을 관측했고 Tab/Enter 확정 후 클릭4개는 정상입니다. 자료·감사 변경0이며, 별도 준비 실패가 아닌 실제 사용자 흐름 결함으로 후속 최소 교정·재검수합니다.
- 대출 삭제 확인창의 실제 부모복귀도 별도 실제 검수 중입니다. 위62개 성공을 이 경계까지 완료한 근거로 확대하지 않습니다.
