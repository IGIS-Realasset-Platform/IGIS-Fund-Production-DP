# REPORT128 — 국토부 보고서 작업영역 정렬

기준: 2026-10-27 사용자 요청4, 공통 요구 **RPT128-04**. 현재 정식 v0.12.7 C61의 보고서 화면을 대상으로 합니다. 아래 REPORT128-01~04는 세부 검사 이름이며 공통 매트릭스의 RPT128-SELECT/TOOLS/SOURCE/EDITOR에 대응합니다. 구현·논리검사·실제 화면 검사는 별도로 판정합니다.

## 확인한 문제와 수정 범위

- C60 1440×900 기존 캡처에서 보고 종류·기준일이 각각 약670px로 늘어나고 사업비 기준은 다음 줄 절반만 차지합니다. C60→C61에서 보고서 모듈/스타일은 변경되지 않았습니다. 해당 캡처는 기존 화면 참고이며 새 후보 실제 검수를 대신하지 않습니다.
- 기재자료 확인과 저장한 보고서 보기는 별도 전체폭 패널에 있어 같은 보고서 작업과 떨어져 있습니다. 별도 패널/중복 제목을 없애고 작성 패널 오른쪽에 둡니다.
- 보고 종류→보고 기준일→사업비 확정시점은 같은 보고서의 작성 조건이므로 데스크톱 한 줄, 좁은 화면 한 열로 묶습니다. 날짜의 과도한 가로폭을 제한합니다.
- 보고서 내용 수정·미리보기·인쇄/PDF·작성본 저장은 조건 바로 아래 같은 크기의 버튼으로 유지합니다. 주요 행동은 기존과 같이 보고서 내용 수정 하나입니다.
- 법적 적용 여부·시행일과 실제 법령/서식 링크는 보고와 관계있는 참고이므로 보존합니다. 별도 안내 패널·신규 단계·설명용 팝업은 만들지 않습니다.
