# 로컬 작업실 공통 디자인 명세

기준일: 2026-11-10. 범위는 `http://127.0.0.1:4178/`의 로컬 작업실입니다. 참고 화면은 사용자가 지정한 Workplace Seoul(`http://127.0.0.1:5173/`)입니다. 운영 게시본 C100의 검수·배포 상태와 별도로 관리합니다.

## 승인과 보존 경계

사용자는 제안한 가이드라인을 전체 UI에 적용하고, 참고 사이트의 왼쪽 메뉴 폭·메뉴별 아이콘·간격도 적용하도록 승인했습니다. 이 승인은 로컬 작업실의 기존 글자 전용 메뉴 지시를 대체합니다. 운영 사이트의 메뉴 정책·게시 파일·데이터에는 적용하지 않습니다.

원본 A·B·C 사업, 명칭·금액·날짜·검토의견·조치계획, 저장된 로컬 편집자료, 계산·합산·권한·저장·취소·내보내기 기능을 보존합니다. LOCAL-UI-22는 명세 화면과 관련 복사·다운로드 조작을 원본대로 복원하며 LOCAL-UI-08의 로컬 예외를 대체합니다. 새 사업이나 값은 만들지 않습니다. 제거된 상단 통계박스와 비교바를 되살리지 않습니다. 국토부 보고서의 독립 iframe 본문·인쇄 서식·과거 확정본에는 공통 디자인을 주입하지 않습니다.

## 정렬 원칙 — 2026-11-10 추가 지시

컴포넌트를 배치하기 전에 같은 업무 구역의 공통 기준선을 정합니다. 제목·필터·표·하단 동작은 같은 좌우 내용선을 공유하며, 표가 패널 가장자리까지 펼쳐지는 경우에는 첫/마지막 셀의 내부 여백을 포함한 글자 기준선을 맞춥니다. 패널 본문과 내부 도구모음이 각각 패딩을 더해 검색창만 이중으로 들여쓰기되지 않게 합니다.

같은 행의 입력창·선택창·버튼은 상하 끝선과 높이를 맞춥니다. 라벨이 있는 폼과 없는 버튼이 섞이면 입력 영역의 아래쪽 기준선에 맞추고, 라벨/오류는 별도 공간으로 처리합니다. 같은 역할의 입력은 같은 폭 기준을 사용하며 검색어·날짜·짧은 상태·긴 이름의 서로 다른 역할을 모두 같은 폭으로 강제하지 않습니다. 화면이 좁아져 다음 줄로 이동하면 새 행도 동일한 기준선에서 시작합니다.

사업비처럼 실제 열이 많은 표는 원래 열폭·금액 정확도·가로 스크롤을 보존합니다. 정렬 검사는 표의 전체 스크롤 폭을 필터 폭과 억지로 같게 만드는 검사가 아니며, 화면에 보이는 스크롤 영역과 패널의 좌우 경계를 대조합니다. 고정 식별열과 스크롤 숫자열의 역할도 구분합니다.

현재 연결된 수정은 패널 본문 바로 아래 도구모음의 중첩 패딩 제거입니다. 이것만으로 전체 화면 정렬을 통과 처리하지 않으며, 세로로 반복되는 카드·병렬 패널·폼·모달의 시작/끝선, 긴 항목·오류·모바일 줄바꿈을 별도로 검수합니다. LOCAL-UI-07의 범위별 결과는 아래 검수 결과로 관리하며 전체 UI 수락으로 확대하지 않습니다.

## 플랫폼 명세 정리 이력 — LOCAL-UI-08 (LOCAL-UI-22로 대체)

읽은 원본은 `src/spec.js`의 현재 spec 화면 등록부(개요·기능정의서·SDD·TDD·검수·데이터 구조·개발이력·피드백·전체 JSON)입니다. 피드백 탭은 과거 요구·결정·피드백 JSON을 보여 주며 사용자가 의견을 작성하는 기능이 아닙니다. 화면 상단의 JSON 복사·명세 내려받기·전체 데이터 내려받기도 내부 화면의 조작입니다.

## LOCAL-UI-93 원가관리 탭과 원가현황 카드

계약·집행 요약은 최상위 원가항목별 `cbsFunds` 결과를 더합니다. 계약금액은 기준일에 적용되는 사업비 반영 계약액과 이관 잔액, 지급금액은 기준일 이내의 사업비 반영 지급액과 유효한 이관 지급액을 사용합니다. 기성금액은 원가항목별 기성 배부 또는 이관 기성액입니다. 미지급금은 이관 자료가 있는 항목에서 기성액과 지급액의 차이이며, 그 외 항목은 배부된 확정 지급조건에서 그 회차에 연결된 지급액을 뺍니다.
