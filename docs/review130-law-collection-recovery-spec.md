# REVIEW130 — 자연 법령 수집의 부분실패 복구

2026-10-29 자연 예약의 추가 결함입니다. 최신 표/비교 UI 수정과 별도 서버 보완이며 기존 서비스·다른 스키마·화면 업무 판단은 바꾸지 않습니다.

## 실제 관측과 요구

08시 실행은376개 중162확인/214실패,09시 복구는310확인/66실패로 두 번 모두 약181초에 종료했습니다. 첫 성공162개가09시에도162개 모두 다시 수집됐습니다.09시66개 실패는 공식 API40423개와 시간예산43개이며,08시40417개는09시에 모두 성공해 고정된 없는 ID로 단정할 근거가 없습니다.

이전195개 범위의 마지막 성공시각을 새376개 성공으로 표시하지 않습니다. 현재311개 스냅샷도 새310개 확인과 과거 보존분을 포함하므로 전수 성공이 아닙니다. 사용자는 실패 재시도를 백엔드에서 처리하도록 이미 요청했으며 수집 운영상태를 일반 사용자 화면에 새로 추가하지 않습니다.

| ID | 독립 조건 | 통과 기준 |
|---|---|---|

| LAW130-R3 | 이전 부분결과의 원본·실패목록·수집일이 불완전하거나 서로 다름 | 추측으로 재사용하지 않음. 안전한 새 조회 또는 명시적 불일치로 관리 |
