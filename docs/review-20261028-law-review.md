## 전체 검색의 계약

검색 대상에 `전체`를 기본값으로 제공합니다. 저장한 단일 대상 선택은 유효한 작업환경으로 유지하며 선택할 수 있는 공식 범위는 법령·행정규칙·전국 자치법규3종입니다. 모든 기관의 모든 공고를 수집한다고 표시하지 않습니다.

- 공식 API에는 이3종의 단일 all 요청이 없어 서버가3종을 병렬 조회합니다. 단일 대상은 기존20건 페이지, 전체는 종류별 최대20개씩 최대60개를 묶습니다. 전체 페이지 수는 가장 긴 종류의20건 페이지 수이며 단순히 총건수를60으로 나누지 않습니다.
- 다음 페이지는 현재 종류별 총건수를 먼저 확인하고 이미 끝난 종류는 추가 목록을 요청하지 않습니다. 요청 사이 전체건수가 달라지면 해당 종류를 실패로 남겨 조용히 누락/중복하지 않습니다. 외부 대기는 로그인용 DB 거래 밖에서 수행하고 전체 시간예산을 공유합니다.
- 한 종류가 실패해도 다른 종류의 실제 결과는 보존합니다. 실패 종류와 실제 재검색을 제공하며 일부 합계를 완전한 전체 합계/0건으로 바꾸지 않습니다. 모두 실패하면 오류 응답입니다. 일일 수집 운영 상태/이력 패널과 구별되는 해당 검색 요청의 오류 처리입니다.
- 같은 표제/숫자라도 실제 target·판본·시행일·관할을 보존합니다. `전체`라는 가상 target을 법령 등록 요청에 보내지 않습니다. 결과의 실제 종류로 기존 권한·본문 재확인·사업 연결/공용 관리·중복 방지 경계를 통과합니다.
- 검색조건·사업 전환 후 늦은 결과, 실패한 페이지의 이전행 복구, 전체/단일 대상 전환, 재시도는 기존 보존 규칙을 사용합니다.

신규 통합 논리12/12 및 기존 검색21·API9 통과를 확인했습니다. 공개 공식 API에서 검색어`건축`의 page1/2는 각각60건, 총3212(법령1304·행정규칙277·자치법규1631),82페이지, 부분실패false로 직접 확인했습니다. 이는 당시 두 페이지의 공급자 결과이며 사용자별 DB 추가/실제 브라우저/전체 법령 전수 수락이 아닙니다.
