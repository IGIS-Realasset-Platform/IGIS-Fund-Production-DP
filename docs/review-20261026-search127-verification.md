# SEARCH127 검수 기록

정식 기준선은 v0.12.6 C58이며 이번 후보는 v0.12.7입니다. LAW127-01 공식검색 탭과 NAV127-02 메뉴 제어만 교정하며, DB·법령 수집대상·사업자료·계정·기존 서비스는 변경하지 않습니다.

## 기대와 독립 근거

- 공식 법령검색은 국가법령정보센터의 실제 GET 폼을 사용합니다. 법령 `lsSc.do` 1/15/81, 행정규칙 `admRulSc.do` 5/41/183, 조례·규칙 `ordinSc.do` 3/27/139의 menuId/subMenuId/tabMenuId와 `query`입니다. 조례는 지역 제한 인자를 넣지 않아 ‘시도전체’로 진입합니다.
- 공식 폼3개와 실제 GET9개의 한글·공백·특수문자 전달을 독립 대조했습니다. 해당 사이트의 모든 법규 완전성이나 JS 결과행 검수로 확대하지 않습니다. ELIS는 보조 경로로만 조사하고 중복 선택지를 만들지 않습니다.
- 제어는 [Fluent 2 Nav](https://fluent2.microsoft.design/components/web/react/core/nav/usage/), [Atlassian Navigation](https://atlassian.design/components/navigation-system/layout), [W3C Button](https://www.w3.org/WAI/ARIA/apg/patterns/button/), Lucide PanelLeftOpen/Close의 확인한 공식 원본을 참고했습니다. 기존 그림 없는 메뉴 항목과 전체 숨김은 유지하고 상단 제어만 기호로 바꿉니다.

구현·자동검사·실제 Edge·공식 사이트 연결·정식 서버 결과를 아래에서 구별합니다. 검색 탭 진입은 관리자료 로딩·실패와 무관해야 합니다. 잘못된 명시 대상은 law로 조용히 바꾸지 않으며, 빈 검색·잘못된 대상에서 새 탭·업무 저장은0입니다. 검색어를 제출하지 않고 탭을 왕복해도 대상·검색어를 보존합니다.
