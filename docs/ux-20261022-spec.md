# 업무 정보 중심 UI 교정 — UX122

기준일: 2026-10-22. v0.12.1 정식 C29 이후 사용자의 비용 정보창·법령 목록·법령 상세 지적을 반영합니다. 이 문서는 구현·검수·게시를 구별하며 현재 작업 버전은 v0.12.2입니다.

## 사용자 흐름과 보존 경계

- 비용: 본표 → 관리 → 필요한 명령 → 저장/취소 → 같은 표·행·스크롤·포커스. 작은 메뉴는 행 높이를 늘리지 않고 끝행·390px에서도 잘리지 않아야 합니다. 모르는 표시그룹에 가짜 원장 ID로 금액/세액 명령을 전달하지 않습니다.
- 이름/분류 수정 중 사업·대상·기준금액이 바뀌면 차단하고 입력을 보존합니다. 동일 내용 재조회나 무관한 비용 변경까지 막지 않습니다. 없는 폼 키로 기존 분류·VAT·합산역할을 초기화하지 않습니다.
- 법령: 목록 → 상세 → 공식 비교/원문, 닫기 → 기존 목록 문맥. 상세 1건만 필요시 조회합니다. 닫은 뒤 늦은 응답이 다른 상세를 덮지 않아야 합니다.
- 개정 조문과 ‘생략/현행과 같음’은 구별합니다. 공식 변경 본문을 확인하지 못하면 법령 이름을 변경 내용으로 꾸미지 않습니다.
- 로그인·기존 사용자·공유 Auth·다른 서비스·다른 DB 스키마·기존 금액·계약/VAT·확정본·검토판정·원문 수집/식별 알고리즘·보고 양식은 변경하지 않습니다.
- v0.12.1 정식 배포와 샘플 보완·1원 저장/재접속/복원은 당시 사실로 보존합니다. 새 UI의 화면 검수로 자동 승계하지 않습니다.
