## 고정한 반례와 교정 경계

조건을 지워 저장한 `height:null`·`floors:null`·`siteArea:null`·`region:''`가 기존 병합 함수에서 버려졌습니다. 이에 따라 기본정보의200m·50층·10만㎡·서울 값이 다시 살아나 추천을 바꾸었습니다. 없는 값과 사용자가 명시적으로 비워 둔 값의 구분이 필요합니다.

- 명시적 공란·null은 미확인으로 보존하고, 명시적0은0으로 보존합니다.
- 사업별 조건이 아예 없는 필드에만 기본정보를 최초 기본값으로 제시합니다.
- 추천은 검토 후보이며 법적 적용·승인·일정·사업 원장을 자동 확정하지 않습니다.
- 규칙이 아직 없는 항목도 전체 선택에서 계속 접근할 수 있습니다. 미확인을 해당 없음으로 바꾸지 않습니다.
- 조건·추천 정의를 공유 순수함수로 모으고, 선택 UI는 같은 정의를 사용합니다. UI와 서버의 실제 관계·회차·날짜 검증은 보존합니다.
- 새로운 법정 대상 수치·지방 절차·유형명은 공식 조문과 원본 대조 없이 만들지 않습니다. 추가 추천 규칙은 독립 근거 검토 후 반영합니다.

자동검사·실제 화면·저장/실패/재접속은 별도 단계로 기록합니다. 실제 DB·스키마·기존 법령 수집·원판본은 이 조사·순수검사에서 변경하지 않습니다.
