## 등록 정보의 소비자

등록·초안 저장/재개·검증·취소·저장실패 → 사업개요 조회/수정 → 중앙 원장 저장/재접속 → 이력/자료 내보내기 → 국토부 보고서 기존 매핑을 대조합니다. 펀드 정식명은 `basic.fundName`, 파이낸스 구조 설명은 `basic.financeStructure`, 담당자 원천 참조는 `basic.managerRef {employeeId,name,email}`로 저장합니다. 기존 `basic.manager` 표시값과 연결 원천을 함께 검증하며 기존 사업은 이름으로 자동 연결하지 않습니다. 파이낸스 구조 설명은 실제 대출·출자 원장과 구별해 보존합니다.

기존 자료의 읽기/이관 API와 새 등록 양식은 버전으로 구분합니다. 새 양식은 `development-overview-v2` 계약을 명시하며 서버도 같은 계약을 검증합니다. 기존 저장자료나 합성 회귀검사의 역사적 등록 계약을 미완료 신규 양식으로 잘못 변환하지 않습니다.

## 완료 증거

명세·구현·실패재현/집중검사·최종회귀·실제 화면·실제 서버/DB·Excel/PDF·배포를 각각 기록합니다. 현재 준비·구현·자동검사 상태를 실제 배포 완료로 확대하지 않습니다. 전체 검수 실행기는 이번 REVIEW132 신규 시험을 포함하고 실행 중 소스 변경을 확인합니다.
