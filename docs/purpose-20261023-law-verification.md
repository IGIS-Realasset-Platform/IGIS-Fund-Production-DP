# 법령·조례 연결 검수 — LAW125

2026-10-23, v0.12.5 후보 소스의 제한된 교정·검수 기록입니다. **법령 연결의 정확성을 검사한 것이며 개별 사업의 법적 적용·면제·완료를 확정한 기록은 아닙니다.** 배포·실제 브라우저·전체 플랫폼 수락과도 구분합니다.

## 수정한 경계

| 경계 | 현재 계약 | 재발검사 |
| --- | --- | --- |
| 정확한 법령명 | 정식명 안의 ‘및’은 보존하고, 별개 법령 사이의 구분자만 분리합니다. 기존 이름식별과 같은 공백·가운뎃점 중립 기준을 사용합니다. 법률·시행령·시행규칙은 구별합니다. 공백뿐인 이름은 빈 검색키로 반복하지 않습니다. | LAW125-01~03·21~22 |
| 조례 관할 | 도·광역시까지만 있고 필요한 시·구가 없으면 확인 부족(`insufficient`)입니다. 실제 다른 시·구는 연결되지 않음(`not_linked`)으로 구별합니다. 어느 경우도 법률상 무관을 자동 확정하지 않습니다. | LAW125-04~06·12, 기존 후보검사 |
| 같은 법령 재사용 | 이름만으로 기존 공통 확인목록(`global watch`)을 재사용하지 않습니다. target과 공식 법령ID 또는 정확 판본을 확인하고, 알려진 기관·관할의 충돌을 무시하지 않습니다. 빈 식별값끼리 같은 대상으로 보지 않습니다. | LAW125-07~11·13~18 |
| 기존 구판본 | 공식 구판본 URL밖에 없으면 기존 공식 상세 조회를 한 번 더 수행해 동일 법령을 대조합니다. 원래 공통 목록의 메타정보를 추측 보강하거나 다른 관할로 바꾸지 않습니다. | LAW125-14~18 |
| 비동기 저장 | 공식 조회는 DB 처리구간 밖에서 수행합니다. 재조회 뒤에는 같은 세션·사업·권한과 공통 목록 식별 메타를 다시 검사합니다. 교체·충돌은409, 원문 조회 실패는503으로 처리하며 다른 법령으로 대체하지 않습니다. | LAW125-15~19, 기존 watch검사 |
| 서버 반환·시간 제한 | 실제 `createWorkspaceRuntime`이 요구하는 `Response`와 세션 쿠키 갱신 계약을 유지합니다. 두 공식 조회는 `Date.now()` 기준의 같은30초 제한을 공유하고, 예산 소진 뒤 추가 요청을 시작하지 않습니다. 업무 기준일용 `clock`과 경과시간을 혼용하지 않습니다. | LAW125-19~20 |
| 업무 원문 | 조회가 사용자 검토·인허가 진행일·완료상태를 생성하거나 바꾸지 않습니다. 추천·의제 관계를 실제 완료로 승격하지 않습니다. 전문인력·교육·등록·보고 등 무관한 부분도 보존합니다. | LAW125-06·12, 인허가·전문인력 회귀 |

`고양시외지역`이라는 합성문구를 명확한 타지역의 근거로 사용하던 옛 검사자료는 실제 다른 시인 `성남시`로 교정하여 기존 음성 기대를 유지했습니다. 합성문구 자체는 원문 보존·후보 생성 없음·확인 부족의 별도 반례로 남겼습니다. 단언을 단순 완화한 변경이 아닙니다.

## 실제 DB에서 읽기만 확인한 사실

앱 전용 `development_project_platform`의 확인목록2개 테이블 제약 및 공통 목록의 키·URL 형식별 **집계만** 확인했습니다. 원문 행·직원·댓글·인증값·업무자료를 이 문서나 테스트 결과로 공개하지 않습니다.

| 확인 항목 | 결과·한계 |
| --- | --- |
| 실제 유일제약 | `law_watchlist UNIQUE(target,name)`, `law_project_watches PRIMARY KEY(project_id,watch_id)`와 외래키가 있습니다. 동명 다른 관할을 새 공통 행으로 삽입해 우회하지 않습니다. |
| 기존 공통 목록 | 194개: 법령180·행정규칙4·조례10입니다. `source.lawId/sequence/agency/agencyCode` 키는 없었고, 조례10개에는 별도 관할값이 있었습니다. 새 메타키를 가진 모의자료만으로 호환성을 판정하지 않았습니다. |
| 공식 판본 URL | 188개에 공식 판본번호가 있었습니다. 이 중 국가법령174개에는 URL 시행일 형식도 있었습니다. 정확 같은 판본은 즉시 재사용하고, 다른 판본은 공식 원문을 대조하는 경로를 검사했습니다. **실제188개 원문을 모두 재조회해 성공했다는 뜻은 아닙니다.** |
| 이름경로 URL | 법령6개는 판본을 식별할 정보가 없었습니다. 이름만으로 같은 법임을 추측하지 않고409로 연결을 차단합니다. 기존 자료를 삭제·재분류하거나 자동 보강하지 않습니다. |
| 수집기와 초기자료 | 현재 수집기는 `source:watch.source`를 그대로 전달합니다. 초기 일회성 자료 작성기는 현행·보존 스크립트 검색에서 찾지 못했습니다. 실제 키 부족과 검사자료의 준비 문제를 구별했습니다. |
| 변경 여부 | 이번 교정의 실제 DB 쓰기·DDL·다른 스키마 변경은0입니다. 기존 유일제약을 변경하지 않았습니다. |

유효한 서로 다른 공식 메타를 주입한 동명 조례 반례는 **격리된 API 검사**입니다. 특정 동명 조례가 실제 원사이트에 존재한다는 실사례 조사로 확대하지 않습니다.
