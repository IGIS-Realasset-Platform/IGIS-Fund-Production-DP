## 보존 경계

- 기존 회사 서비스, 다른 DB 스키마, 인증 설정·접근권한은 바꾸지 않습니다. 이 앱은 `development_project_platform`만 사용합니다.
- 법령 검색은 읽기이며 관리 편입은 사용자의 명시적 추가로만 수행합니다. 기존 `/api/law-search`·`/api/law-watch`와 저장·수집 경로를 재사용하고 새 DB 구조를 만들지 않습니다. 사업과의 연결이 법적 적용 확정을 뜻하지 않습니다.
- 전국 조례를 검색할 수 있다는 사실을 전국 모든 조례의 사전 등록·수집 완료로 표시하지 않습니다. 관할·공식 식별자·판본 확인을 기존 경계대로 보존합니다.
- 개인 알림 읽음·삭제는 개인 상태만 갱신합니다. 화면 준비를 막거나 작업공간 전체 저장을 발생시키지 않습니다.
- 보고서 화면의 근접성과 크기를 교정합니다. 원본 법정양식, 출력 필드·단위·금액, 과거 보고본·확정본, 편집본 저장과 플랫폼 반영의 구별은 유지합니다.
- 4261개 기존 매트릭스 행과 이전 검수는 보존합니다. 이번 요구·구성요소를 먼저 추가하고 정확한 소스/HTML에 검증 증거를 연결합니다. 일부 통과를 전체 플랫폼 수락으로 확대하지 않습니다.

1. 현재 원인과 독립 기대값을 고정하고 실패검사를 실행합니다.
