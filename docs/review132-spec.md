## 역할과 증거

클라이언트 성능 담당과 알림·서버 담당은 루트 작업 소스에서 책임 파일만 수정합니다. 보안 감사는 게시된 C93 Git 소스를 읽기 전용으로 고정하고 독립 검토하며, 확인된 수정은 작업 소스에 적용합니다. 루트는 경계·우선순위·교차 검토·실제 검수·릴리스를 조정합니다. 4개 동시 작업 슬롯을 역할별로 재사용하며 필요가 끝나면 다음 역할에 넘깁니다.

화면 또는 API가 존재한다는 사실, 정적 문자열·ID·HTTP200·일부 모델 통과를 전체 정상으로 확대하지 않습니다. 알림의 변경이 필요하면 기존 정책의 모순·오류를 먼저 입증하고, 수신 대상의 임의 확대나 새로운 업무 정책은 추측하지 않습니다. 관리형 보안 검수 결과는 해당 스캔의 정식 저장소에 보존하고 이 명세에는 연결만 남깁니다.

현재 상태: 조사·실패검사 준비 중. 제품 완료·실제 배포·전수 무결성은 아직 수락하지 않았습니다.
