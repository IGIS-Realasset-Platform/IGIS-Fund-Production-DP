# AUTH132-11 추가 샘플 조회 접속 검증

추가 승인된 6명의 회사 이메일을 조직 원천에서 정확히 확인하고, 기존 접속 명단을 보존한 채 별도 비공개 설정에 등록했습니다. 이 준비 시점의 기존 계정은 0개입니다. 실제 이름·이메일·키값은 공개 소스·검사·문서에 넣지 않습니다.

허용 범위는 엄격히 식별된 A/B/C 샘플 3개 조회입니다. 데이터 등록·수정·삭제·확정·접근관리와 전역 회사·직원·법령·댓글·외부자료는 서버에서 차단합니다. 화면 메뉴를 숨기는 것에만 의존하지 않습니다. 개인 알림 읽음·삭제·복원은 본인의 허용 샘플 알림에만 적용합니다. 저장본과 보고서의 본문도 샘플 원천 표식을 확인합니다.

기존 12명 정책·응답 형태는 유지하고, 추가 명단이 겹치면 조회 전용 제한을 우선합니다. 처음 가입하고 회사 이메일 인증을 마치면 세 샘플의 조회 권한을 받습니다. 계정·암호를 선발급하거나 초대/인증메일을 미리 보내지 않았습니다.

서버 의미검사15·실제 Better Auth 무송신 검사5·클라이언트23개와 백엔드 영향 회귀29개 실행파일을 통과했습니다. 이전 계정 요청의 늦은401 응답이 새 계정을 로그아웃시키던 한 원인/두 소비자를 수정하고 독립 재현2개도 통과했습니다. 조회 목록에 잘못 들어 있던 쓰기 양식 버튼2개를 제외했으며, 기존 개별 폼·서버의 쓰기 차단은 원래부터 있었습니다. 이 오분류를 서버 권한 우회로 부풀리지 않습니다.

설정 등록은 기존18개 환경설정 메타정보 불변을 확인했습니다. 기존 민감 명단은 복호화하지 않았으며 regular/sample/union/overlap의 실제 수치는 새 배포의 정상 설정 경로에서 숫자만 확인합니다. 이 문서 작성 시점에는 최종 전체검사·정확 게시 파일 화면검수·검증/정식 배포가 진행 중이며, 실회원의 실제 가입·로그인은 미수행입니다. 최종 상태는 같은 이름 JSON과 [현재 검수](review132-final-verification.md)를 따릅니다.
