# 자동 법령 비교·선택 판본 재검토 — 검증 기록 (AUTO123)

작성 기준은 2026-10-22입니다. **C38 법령14흐름 통과·시장 모바일 키보드1실패 재현 뒤 최소 교정, 최종 C40 실제 검수·배포는 진행 중**입니다. 이후 결과는 증거와 함께 갱신합니다. 이 문서는 전체 요구사항이나 운영 전환의 완료 선언이 아닙니다.

결론: 일일 법령 판본 수집은 자동입니다. 신구 조문 비교는 정확한 판본을 식별할 수 있는 **한 건의 상세를 열 때 자동 조회**합니다. 사람이 대비표를 작성하는 방식은 아니지만, 매일 관리항목 194개의 대비표를 전부 미리 생성·저장·검수하는 방식도 아닙니다.

## 4. 캐시·실패·재시도 독립 검사

캐시는 같은 기준정보 세대·브라우저 세션·사업·변경 ID·선택 시행일의 문맥에 한정됩니다. 여기서 ‘세대’는 기준정보를 새로 불러오기 전후를 구별하는 값입니다.

| 응답/상황 | 새 동작과 확인 결과 |
| --- | --- |
| `verified` / `unchanged` | 정상 완료 결과를 재사용합니다. 정상 비교를 다시 열어 GET 합계 1회를 확인했습니다. |
| 공식 미제공 N | 정상 조문 비교 완료와 구분한 `unavailable` 상태입니다. 같은 문맥에서 두 번 더 열어도 GET 합계 1회이며, 거짓 대비표 링크를 숨기고 정확한 원문을 유지합니다. |
| N 이후 갱신 | 상단 기준정보 새로고침·새 세션·내부 명시 `force`에서 다시 확인합니다. N 화면에 실제 없는 ‘다시 시도’ 버튼이 있다고 주장하지 않습니다. |
| HTTP503/429 또는 HTTP200 내부 실패 | 이전/현재 본문 미확보, 식별 불일치, 통신 실패·알 수 없는 응답을 정상 성공 캐시로 삼지 않습니다. 실패 안내·재시도/재열기 요청 후 정상 결과로 회복했습니다. |
| 제공 여부를 모르는 통신 실패 | 공식 N으로 추정하지 않고 기존의 정확한 공식 링크를 유지합니다. |
| N 확인 뒤 실패한 강제 재조회 | 같은 문맥의 기존 N 사실을 유지합니다. HTTP503뿐 아니라 HTTP200 내부 실패도 확인했습니다. 뒤에 실제 정상 비교가 오면 새 결과에 따라 링크가 회복됩니다. |
| 첨부형·지원 불가 | 확인된 공식 첨부와 원문 사실만 사용합니다. 다른 호스트 URL, 다른 과거 판본의 첨부를 현재 자료로 표시하지 않습니다. 조례 원문을 신구표로 바꾸지 않습니다. |
| 문맥·늦은 응답 | 다른 사업·복수 시행일에 결과를 섞지 않으며, 닫거나 다른 폼으로 바뀐 실제 DOM을 늦은 응답이 덮지 않습니다. |
| 원자료 보존 | 모든 검사 자료의 법령 원자료·기존 담당 검토·CBS의 명시 0·확정 시점·감사·로컬/세션 저장값이 전후 일치했습니다. |

### 실패 재현과 새 결과

- 기존 독립 4대조는 정상 비교, HTTP503, HTTP200 내부 `NETWORK_FAILED`, 공식 N을 분리했습니다. 원본 증거를 덮어쓰지 않았습니다.
- 동일한 최종 기대 24개를 불변 C36 법령 2모듈에 다시 실행하면 14실패/10통과, 새 모듈에는 **24/24 통과**했습니다. 구판 재실행은 구현자 수정 뒤 불변 구판을 주입한 재현이며, 수정 전에 이 최종 검사 전체를 실행했다는 뜻이 아닙니다.
- 중간 새판에서 발견한 ‘N 확인 뒤 HTTP200 내부 실패가 N 사실을 지움’ 1실패도 별도로 보존했고, 최소 교정 후 같은 기대값으로 통과했습니다.
- 복수 시행일 검사의 중간 `loading` 관찰 1건은 모의 비동기 작업을 충분히 비우지 않은 검사 준비 차이였습니다. 값 기대를 바꾸지 않고 완료된 작업을 대조했으며 제품 결함 수로 세지 않습니다.
