## 수정과 보존

- 비용 이름 클릭의 기술정보창과 분류기준/원자료 설명 단계를 제거합니다. 본표 관리 메뉴에서 실제 이름/분류/세액/합치기/삭제로 연결하고 같은 셀 금액 편집·직접 이력·하위항목은 유지합니다. 설명창 제거로 닫기 부모가 사라진 기대만 명시 대체하며 실제 하위 부모·금액·세액·계약·확정본 보존 검사는 유지합니다.
- 법령 목록은 다섯 열이며 날짜와 법령/조항에 정렬 버튼을 둡니다. 실제 개정문 또는 정확한 공식 링크를 제시합니다. 공식 법령·행정규칙의 신구조문 화면은 정확 판본ID와 실제 두 열 본문을 대조했습니다. 조례 예제는 실제 원문만 확인됐으므로 비교표라고 표시하지 않습니다.
- 법령 상세를 여는 동작에서 한 건만 필요시 조회합니다. 실제 변경문구는 바로 이어 표시하고 생략/현행같음·작업보고 문장·무근거 전사업 후보표·빈 기록표는 기본 상세에 나열하지 않습니다. 기존 실제 검토기록과 공식 판정 알고리즘은 보존합니다.
- 독립 화면 필요성 감사는 C29의 새58개 관측과 정적164개 팝업/폼 호출을 구별했습니다. 옛 빈 알림의 반복 안내, 시장 수집시각의 발표버전 오표시와 차트 내부 비교축 비율을 최소 교정했습니다. 정상 알림·분기/법령 행동 안내, 실제 잠정/정정판본·관측값·통계원문, 차트 계산·실제 조달 구성비는 보존합니다.
- 계약·담보·원문 증빙·과거 확정본·보고서 수정경계·소유자 명세는 설명창이라는 이유로 제거하지 않습니다.

## 현재 증거 상태

집중검사는 수정 전 실패와 수정 후 통과를 구분합니다. 새 버전 연결 검사의 초기 버전 불일치 및 검사 준비 오류는 제품 결함 재현으로 집계하지 않습니다. 전체 회귀의 첫 발견 실행은 제품 수정 중이어서 소스 변경이 있었고, 다섯 기존 기대 충돌을 발견한 중간 기록입니다. 최종 고정 실행과 실제 화면 검수 결과는 이후 별도로 기록합니다.

정확 HTML C31: `5b9b98a3ee347264e271ed0559e26f748394f8a583d238941ca18e65e2496916`, 6,612,902바이트, v0.12.2. 현재 검수용이며 정식 승격 완료를 뜻하지 않습니다.

전체 화면의 관측 수·정적 버튼 수는 모든 조건·권한·오류·원격 기능 실행의 완료 수가 아닙니다. 다른 서비스·공유 Auth·다른 DB 스키마는 수정하지 않습니다. 가상 A/B/C 원금액은 앞선 C29 실제 검수에서 복원한 상태로 보존합니다.
