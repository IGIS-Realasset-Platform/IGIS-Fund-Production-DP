# 자동 법령 비교·선택 판본 재검토 (AUTO123)

2026-10-22 사용자 요청: 이전 수정사항을 계속 대조하고 신구대비표의 자동 처리 범위를 확인합니다. 기준선은 정식 v0.12.2 C36입니다. 기존 서비스·다른 스키마·금액·원자료·실제 검토기록을 변경하지 않습니다.

| ID | 기대 동작 | 재현·검수 경계 |
| --- | --- | --- |
| AUTO123-01 | 조건을 충족한 법령 상세는 선택한 판본을 자동 조회. 공식 대비표 미제공·첨부형·지원되지 않는 비교와 일시적 조회 실패를 구별 | HTTP200 내부 비교실패를 정상 성공으로 캐시하지 않음. 재시도/재열기 회복. 명시N/확인된첨부형은 거짓 대비표 링크 대신 실제 원문·제개정문·첨부. 제공 여부를 모르는 네트워크 오류는 기존 정확 공식조회 링크 유지 |
| AUTO123-02 | 시장 비교 요약·그래프·축·툴팁이 선택한 자료판본을 같은 의미로 사용 | 서로 다른 월은 선택 양끝만 반영·중간월 최신/결측간격 유지. 같은 월 두 판본은 두 관측을 보존하고 시간 진행처럼 선을 잇지 않음. 명시ID 소실/타계열/null은 최신으로 조용히 대체하지 않으며 유효0은 보존 |
| AUTO123-03 | 전체 요청의 구현/검수/외부조건을 실제 근거와 대조 | 미체크75개를75미구현으로 해석하지 않음. 일일 수집과 상세 비교의 자동 범위를 구별. 194개 전체 대비표 사전 생성/검수 완료로 주장하지 않음 |

현재 자동 범위는 일일 법령 수집과 상세 진입 시 한 건의 공식 비교 조회입니다. 비교표를 사람이 작성하거나 모든 자료의 비교문을 매일 미리 저장하는 방식이 아닙니다. 원천 미제공/첨부·이전판본 부재가 자동으로 해결된다고 주장하지 않습니다.

선택 판본 식별에 원천 배열의 순번을 사용하지 않습니다. 원문 관측의 ID·판본·값 등 전체 JSON 내용을 키 순서와 무관하게 식별하되 새 조회시각을 원문 식별에 섞지 않습니다. 원문이 사라지면 기존 선택을 다른 관측으로 바꾸지 않고 해당 선택이 없음을 표시합니다. 원래 참고 JSON·과거 판본·금액은 수정하지 않습니다.

실제 390px 키보드 검사에서 `focusin → 브라우저 자동 스크롤 → 방금 열린 툴팁 소실`을 재현했습니다. 키보드로 초점을 둔 동일 관측점이 연결·화면 내·현재 초점인 경우만 스크롤 후 툴팁을 다시 배치합니다. 포인터만의 툴팁, 화면 밖·삭제된 요소, 다른 초점, Escape/초점 이탈 뒤에는 기존 숨김을 유지합니다. 다른 요소로 옮길 때 이전 `aria-describedby`를 제거합니다. 공통 툴팁의 이 경계만 보완하고 새로운 패널이나 차트 정책은 추가하지 않습니다.

검사는 독립 기대값의 실패 재현 → 최소 교정 → 집중/인접 회귀 → 정확 HTML의 PC/모바일 → 정식 실제 조회/로그 순서입니다. 서버 정책·새 예약/DB/발송·새 계정은 추가하지 않습니다. 같은 스키마라도 이번에 새로운 실제 업무자료 쓰기를 하지 않습니다.
