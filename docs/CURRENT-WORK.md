- 9개 용도 프리셋과 복합 인허가 조건·맵·하위 버튼의 실제 동작 검수.

- 인허가 장식 입력상태 제거, 의견과 조치계획을 포함한 A/B/C 샘플 보완. 실제 직원·법령·인증자료를 꾸미지 않음.

- 사이드바는 펼침=그림 없는 글자, 접힘=전체 숨김. 바깥 글자 버튼으로 다시 열기. 접힌 상태에도 이름을 유지하는 안은 폐기.
- README·버전·개발자/AI 인계·체크리스트를 실제 구현/검수/배포와 동기화.
