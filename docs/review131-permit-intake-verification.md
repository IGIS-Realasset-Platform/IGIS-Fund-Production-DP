# REVIEW131 인허가 선택·추가 통합 검증

조건과 인허가 목록을 같은 팝업의 두 탭으로 묶었습니다. 조건 변경은 같은 임시 목록에 자동 반영되며 수동 선택·해제와 작성 중인 항목 입력은 보존합니다. 탭 이동은 저장하지 않습니다. 조건만 저장할 수 있고, 항목 추가는 조건·선택 항목을 모두 검증한 뒤 함께 저장합니다.

## 반영·보존 범위

- 조건: 사업유형·방식·지역·규모·부지/건축 조건을 한곳에 배치했습니다. 교통·특수구조·대공방어는 공유 엔진의 기준을 사용하며 새 인허가 유형이나 고정 높이를 추측하지 않습니다.
- 명칭: 공식 표시명, 전체 옛명칭, 검색 약칭을 구별합니다. 군사법13조 협의의 신규 카탈로그 분류만 토지·기반시설로 교정하고 기존 등록행 이름·분류를 재작성하지 않습니다.
- 수정: 인허가·토지 필지/계약/지급회차·분양은 기존 행 수정폼으로 연결하여 셀별 반복 버튼을 제거했습니다. 전체폼이 없는 부지확보11필드는 그대로입니다.
- 보존: 상세4탭·의견/조치·기존 날짜/원금액·과거자료를 변경하지 않습니다. 미입력과0을 구별하고 새 근거파일 경로를 강제하지 않습니다.
- 실패: 다른 사업/변경된 원조건·중복 추가·입력 오류를 저장 전에 차단합니다. 저장 실패는 입력을 남기고 다음 화면으로 전환하지 않습니다.

## 실행한 검사

현재 동결 소스로 집중23그룹 및 인접9묶음, 총10묶음177그룹이 통과했습니다. 실패0·검사 중 추적파일 변경0입니다. 정확 파일 지문과 묶음별 분모는 같은 이름의 JSON에 기록했습니다. 이 수는 고유 기능 수나 플랫폼 전수검수 수가 아닙니다.

초기 분리된 조건 흐름의4개 실패는 보존했습니다. 기존 자식 조건 폼을 요구하는 기대는 같은 폼의 조건 입력 즉시추천으로 대체했습니다. 과거 전체 명칭2개·빈조건을 새 값으로 만드는 기대·조건 탭에서 목록추가를 수행하던 시험 준비만 현행화했으며 저장·실패·자료 보존 단언을 유지했습니다.

추가 성공 뒤 단순 닫기와false 반환 때문에 같은 공통 폼 세션이 과거 기준으로 돌아가 가짜 미저장 상태가 되는 경계를 실제 공통 폼 코드로 재현했습니다. 현재는 저장 확인과 활성 문맥을 통과한 추가만 정상 종료로 반환하여 폼 세션/초안을 제거합니다. 조건 저장 후 새 목록폼으로 전환하는 흐름과 실패·늦은 응답은 구별합니다.

## 아직 이 문서가 수락하지 않는 범위

이 검사는 무동작 DOM 모형 및 실제 공통 폼 세션 코드의 제한된 실행입니다. 화면 크기별 실제 표시·키보드·스크롤, 실제 서버/DB 저장, 정식 배포는 root와 독립 담당자의 별도 증거로 확정해야 합니다. 503는 UI 대기 거절 모형이며 중앙 거래의 롤백 검사를 대신하지 않습니다. 이 담당자의 실제DB 쓰기·새 브라우저 기동·배포는 모두0입니다.
