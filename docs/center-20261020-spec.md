## 서버·브라우저 공통 계약

기존 workspace/project-access API와4MB/CAS 계약 유지. 아래 자료는 서버 소유 별도 테이블이며 구형 workspace PUT가 덮지 않습니다. 모든 사용자 API는 기존 세션·allowlist·동일Origin 검사를 재사용하고 `Cache-Control: no-store`를 적용합니다. 입력·인증·권한·미존재·기한·충돌·크기/형식·요청제한·연결 오류를400/401/403/404/408/409/413/415/422/429/503 등으로 구분하며 민감한 내부 원인을 응답에 넣지 않습니다. 유지관리의 부분실패207은 아래 작업별 결과와 함께 판정합니다.

### 개인 알림 `/api/notifications`

- GET: `{states:[{notificationId,readAt,deletedAt}],tasks:[...quarterlyTaskMetadata],alerts:[...lawReviewAlert]}`. 상태는 현재 회원 것만 반환. 업무 알림은 기존 안전한 프로젝트 원장에서 생성하고 법령 알림은 명시 구독 이후의 신규 변경과 읽을 수 있는 현재 사업만 연결합니다.
- PATCH JSON `{notificationId,action:'read'|'delete'|'restore'}` → `{state:{notificationId,readAt,deletedAt}}`. 원업무 삭제나 완료 아님. 읽을 수 있는 사업에서 실제 생성 가능한 알림/서버과제만 허용. viewer도 개인상태 수정 가능.
- 브라우저는 popup을 열 때마다 소형 GET으로 개인상태·과제·법령 알림을 갱신하고 PATCH만 수행합니다. 낙관 갱신 실패시 행·선택·scroll 복원. legacy dismissed는 그대로 보존하고 개인 귀속을 추정하지 않습니다. 초기 상태를 아직 읽지 않았다면 숫자0이나 안 읽음0으로 표시하지 않습니다.

### API 인증값 등록 후 읽기 전용 연결검수 — 2026-10-21

`GET /api/maintenance?mode=verify-provider-connections`는 기존 `CRON_SECRET` 인증을 먼저 통과한 운영 검수 전용 분기입니다. 새 사용자 화면·인증 수단·DB 저장 기능은 만들지 않습니다. OpenDART의 당일 공시1건과 기존 나라장터 공사계약 서비스의 당일1건을 각각 한 번만 요청하며, DB 드라이버를 불러오기 전에 반환합니다. 최대2요청·30초·응답당128KiB/전체256KiB, 재시도·리다이렉트0입니다.

설정 존재·HTTP200만으로 인증 성공을 표시하지 않습니다. 공식 상태코드와 본문 구조로 정상/자료없음/인증실패/서비스 이용승인 부족/요청제한/통신·형식 오류를 구분하고 상태·코드·집계만 반환합니다. 키·원문·요청 URL·기관 오류문구는 반환하거나 로그하지 않습니다. G2B 키는 원문과 한 번 percent-encoded한 표현을 지원하되 재귀 디코딩·제어문자·URL 삽입은 거부하고 저장된 환경값은 변경하지 않습니다. 실제 키의 유효성 확인은 새 환경을 적용한 배포에서 별도 수행합니다. 키 인증 성공과 회사 법인 식별·전체 공시/계약 이관 완료는 다른 판정입니다(`center120-provider-connections`).
