## LAW127-01 — 별도 공식 검색 탭

법령 변경 페이지에 공식 검색 탭을 제공합니다. 사용자가 키워드와 검색 대상을 선택해 실행하면 공식 사이트의 해당 검색 결과를 **새 탭**으로 엽니다. 전국에서 검색할 수 있다는 사실을 플랫폼의 등록 목록·일일 확인 완료로 표현하지 않습니다.

| 구성요소 | 업무 목적과 입력/결과 | 연결·보존 조건 |
|---|---|---|
| 공식 검색 탭 | 현재 관리목록과 구별되는 외부 공식 검색 진입 | 기존 법령 변경·관리목록과 인허가/사업별 검색 진입을 잃지 않음. 실제 탭 키·등록 동작은 구현 후 연결 |
| 키워드 | 사용자가 찾을 법령·조례 이름/검색어 | 공란 실행은 해당 입력의 오류로 안내. 한글·공백·특수문자는 공식 인자 규칙에 맞게 인코딩. 기존 프로젝트 이름을 검색어로 임의 생성하지 않음 |
| 대상 선택 | 공식 사이트가 지원하는 국가 법령/조례 검색 범위를 선택 | 공식 허용값·경로는 확인된 근거만 사용. 관할 미입력을 전국 조례 수집 또는 특정 지역 적용 확정으로 바꾸지 않음 |
| 공식 검색 실행 | 선택한 대상·검색어의 공식 결과로 직접 새 탭 이동 | 사용자 실행으로 열린 새 탭의 공식 주소·검색값을 확인. 플랫폼 홈이나 일반 안내로 조용히 대체하지 않음. 외부 탭에서 원래 창에 접근하지 않도록 안전한 링크 연결 |

담당자가 공식 HTML과 GET 응답으로 확인한 검색 대상은 법령 law(`/LSW/lsSc.do`, menuId1/subMenuId15/tabMenuId81), 행정규칙 admrul(`/LSW/admRulSc.do`, 5/41/183), 자치법규 ordin(`/LSW/ordinSc.do`, 3/27/139)입니다. 모두 `https://www.law.go.kr`의 GET `query` 인자를 사용하며 지역 필터를 추가하지 않습니다. 공식3대상 GET9건의200/입력 원문 보존은 담당자 근거에 연결하지만, 정부 JavaScript 결과행·실제 새 탭·결과 완전성은 별도 미검증입니다. 새 플랫폼 API나 DB 스키마를 이 명세에서 만들지 않습니다. 기존 `/api/law-search`와 사업별 확인목록의 등록 흐름을 새 공식 링크의 저장 기능처럼 쓰지 않습니다.

### 검증 흐름과 반대사례

1. PC/390에서 법령 변경 → 공식 검색 탭 → 키워드 입력 → 대상 선택 → 명시적 실행을 확인합니다. Tab과 Enter로도 같은 검색값이 전달돼야 합니다.
2. 국가 법령·조례의 각 지원 대상에서 공식 호스트/경로/인자가 정확한지 확인합니다. 한글·띄어쓰기·`&` 등은 검색어가 잘리거나 다른 인자로 해석되지 않아야 합니다.
3. 빈 검색어·허용되지 않은 대상·미확정/손상된 공식 주소는 기존 화면과 입력을 보존합니다. 임의 최신 결과나 다른 대상의 주소를 대신 열지 않습니다. 최소 글자 수 등 새 제한은 공식 근거나 승인 없이 만들지 않습니다.
4. 새 탭을 닫고 돌아왔을 때 현재 프로젝트·기존 법령 목록/탭·검색 입력·스크롤·초점의 관련 문맥을 확인합니다. 링크 실행만으로 workspace PUT, watch 등록, 수집 요청, 감사 사건이 생기지 않아야 합니다.
5. 공식 사이트의 접근 제한·연결 실패·브라우저 새 창 차단은 실행 환경과 제품의 URL/동작 오류를 구별합니다. 가짜 공식 페이지나 과거 캡처를 실제 결과 도달로 세지 않습니다.

## NAV127-02 — 접기/펴기 뜻이 드러나는 제어

중립 글자 ‘메뉴’만으로 동작을 설명하던 선택은 사용자가 기각했습니다. 담당자가 공식 참고사례로 확인한 **사이드바 패널 접기/열기 기호 버튼**으로 연결합니다. 특정 그림의 모양을 이 문서에서 임의 확정하지 않습니다.

| 구성요소/소비자 | 이번 검증 계약 | 유지하는 경계 |
|---|---|---|
| 기존 공통 사이드바 제어 | 펼침·접힘 두 상태의 기호가 실제 다음 동작을 일관되게 나타내고 접근성 이름/상태도 동작과 일치 | 기존 제어 ID/행동·바깥 재열기 경로. 버튼 크기·배치의 변경은 담당자 확정 근거에 연결 |
| 펼친 메뉴 | 글자 메뉴 목록으로 실제 화면을 선택 | 목록 그림 아이콘을 되살리지 않음 |
| 접힌 메뉴 | 메뉴 전체를 숨기고 바깥 제어로 다시 열기 | 접힘에도 메뉴 이름을 노출하는 과거 안을 되살리지 않음 |
| 키보드·모바일·저장 상태 | Tab 초점과 Enter/Space 한 번 동작, 토글 후 정확한 제어 초점·현재 화면·사업·스크롤 보존, 저장된 접힘 설정과 재접속 확인 | 새 기본 접힘 정책·전역 단축키·본문 기능 아이콘 일괄 변경을 만들지 않음 |

반대사례는 기호 방향과 실제 동작의 반대, 펼침/접힘 둘 다 같은 중립 표시, 이름만 바뀌고 실제 상태가 안 바뀜, 클릭 시 프로젝트 선택칸 이동, 숨은 메뉴의 포커스 잔존, 다시 열기 불가, 한 번의 키보드 조작이 두 번 실행됨입니다. C58의 글자 ‘메뉴’44px 검수는 이번 기호의 의미·실제 조작 통과로 옮기지 않습니다.
