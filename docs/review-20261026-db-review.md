실제 단건 읽기에서 업체 요약의 그룹·시장·과거 발표 항목과 법령 194건/변경 184건의 원필드가 동일함을 확인했습니다. 선택 업체 판본 조회는 기본키 인덱스를 사용했습니다. 이는 **필요한 DB 자료량과 실행계획 확인**이며, 배포 후 응답시간이 몇 초 단축됐다는 실측은 아닙니다.

## 검사와 변경 금지선

수정 전 독립 검사 41조건 중 15조건 실패를 고정했고, 교정 후 41/41을 통과했습니다. 새 검사를 포함한 관련 13묶음도 모두 통과했으며 검사 중 소스 변경은 없었습니다. 기존 검사 4파일은 새 SQL의 정확한 별칭·반환 모양·인자를 지원하는 모의응답 분기만 고쳤습니다. 원 fixture·정확 ID·선택 판본·검사 개수와 기대 단언은 보존했고, 지원하지 않는 SQL을 임의 빈값이나 전체 payload로 통과시키지 않습니다.

다른 AI가 이어서 수정할 때도 아래 경계를 유지해야 합니다.

- **PUT의 잠금·CAS·409는 유지합니다.** CAS는 읽었던 revision이 현재와 같은지 확인해 다른 창의 저장을 덮어쓰지 않게 하는 비교입니다. GET 잠금을 없앤 것을 쓰기 잠금까지 없애라는 근거로 사용하지 않습니다.
- **감사와 재요청 이력을 유지합니다.** 동일 요청의 재실행 판정·원자적 저장·실패 시 전체 원복·권한 재검증을 바꾸지 않습니다. 과거 응답을 현재 원장으로 대체하거나 감사/판본을 삭제하지 않습니다.
- **조회 결과의 의미를 유지합니다.** 선택한 판본을 최신본으로 몰래 바꾸거나 없는 자료를 가짜 빈 성공으로 만들지 않습니다. 인증 계층의 정상 세션 처리와 업무 GET의 무변경을 구별합니다.
- 이번 승인은 조회 코드에 한정됩니다. RLS·역할·연결 설정·DB 구조·인덱스·보관 정책·다른 스키마의 변경 승인이 아닙니다.

## 남은 개선 후보와 미검증

현재 중앙 원장은 사업 3개를 하나의 JSONB 문서로 저장합니다. 함께 저장하고 복원하기 쉽고 충돌도 감지하지만, 이용과 수정이 늘면 서로 다른 사업의 저장도 같은 원장 revision을 두고 충돌할 수 있습니다. 원장 PG 텍스트는 약 2.78MB이며, 과거 법령 관련 배열도 함께 보존되어 있습니다. 현재 자료를 삭제하거나 구조를 분리하는 작업은 이번에 하지 않았습니다.

감사 34건과 재요청 응답 34건의 저장 본문은 합계 약 31MB입니다. 법령 10개·업체 17개 판본도 누적되어, 이 스키마의 테이블·인덱스·부속 저장공간은 관측 당시 합계 89,030,656바이트였습니다. 변경 이력과 동일 요청의 정확한 응답을 보존하기 위한 비용이며, 장기 성장과 보관 방식을 별도로 검토할 후보입니다. 임의 기간 삭제나 중복 제거를 승인한 것은 아닙니다.

코드는 DB 연결을 재사용하는 풀에서 인스턴스당 동시 연결을 1개로 제한하며, 앱 DB 역할의 연결 상한은 6개입니다. SQL 제한시간은 10초입니다. 관련 조회는 행마다 추가 요청하는 방식 대신 묶음 조회를 사용하지만, 외부 법령 조회 중에도 인증 트랜잭션과 연결을 유지하는 경계는 남습니다. 실제 연결 설정값이나 비밀을 읽지 않았으므로 현재 배포의 풀러 접속 방식·동시 부하·연결 대기시간은 확인하지 않았습니다.

최신 법령 payload의 **PostgreSQL 텍스트 표현은 약 4.93MB**입니다. 이는 실제 API의 공백 없는 JSON, 추가 응답 항목, HTTP 전송 바이트와 같지 않습니다. Vercel의 일반 함수 [요청·응답 크기 제한](https://vercel.com/docs/functions/limitations)과 대조하려면 실제 최종 응답을 따로 측정해야 합니다. 이번 자료만으로 현재 413 오류나 정상 여유를 단정하지 않습니다. 법령 조회 응답의 판본·개정문·원문 연결을 지우는 방식으로 크기를 맞추는 것도 이번 승인 범위가 아닙니다.

검수용 통합 집계의 제한시간 취소와 준비 SQL의 잘못된 타입 선언은 작은 읽기 쿼리로 나눠 확인한 **검사 준비 문제**로 별도 기록했습니다. 제한시간을 늘리지 않았으며 서비스 장애나 재연결 필요로 분류하지 않았습니다. 새 코드의 실제 배포·최종 HTTP 응답 크기·실회원 동시 저장·전체 운영 성능은 이 문서의 완료 범위가 아닙니다.
