## 데이터와 업무 기준

- 앱 전용 `development_project_platform`만 사용합니다. 기존 회사 서비스·다른 스키마·공유 Auth·로그인/권한 설정·실제 사업은 바꾸지 않습니다.
- 현재 가상 A/B/C의 DB 원장 revision34/MD5 `6838bc19114ea96d076cc5257b70b5c0`를 시작 시 읽기전용 확인했습니다. 실제 source는 `.build/review-20261028/db-report-source-before.json`, SHA `77513897c2be762f3f1d93a322f40da47f5910092136dd1363336db8e8e0d44c`입니다. 과거 중복 payload인 reports/reportSnapshots만 명시 제외했으므로 과거본 보존은 별도 원본 hash로 검사합니다. 원천을 GitHub/HTML에 복사하지 않습니다.
- 보고서만의 문구/기재와 공유 원장 값을 구별합니다. 기존 `보고서만 저장 / 플랫폼에 반영`의 명시 선택을 유지합니다. 합성 문구·고정 제목·동결 당시값·복수 원천 셀을 무조건 전역 수정하지 않습니다.
- 전수 입력 검토는 실제 빌드35모듈을 기준으로 합니다. 정적 call/HTML/field선언 후보와 실제 고유 입력·동적 실행의 분모를 구별하고, 미해결 동적 표현은 오류/통과로 숨기지 않습니다.
- 라벨에 숫자 단어가 있다는 이유만으로 타입을 바꾸지 않습니다. 사업자번호·계좌·전화·우편·문서/판본ID와 복합 층수는 식별문자/복합값일 수 있습니다. 저장 원문과 원 단위를 먼저 대조합니다.
- 선택 입력은 표준옵션 밖 기존 값을 지우거나 첫 항목으로 바꾸지 않습니다. 날짜가 아닌 기존 `해당 없음`도 공란으로 숨기지 않습니다. 실제 수정한 값과 원문 보존을 구별하며 날짜마다 임의의 `입력 여부` 선택칸을 추가하지 않습니다.
- 미입력/공백→0, 0→미입력, 선택 안 함→아니오·첫 항목을 자동 생성하지 않습니다. 새 법령·항목·명칭을 추측으로 추가하지 않습니다.
- 레퍼런스는 공식 API/법령·원서식과 공식 디자인 시스템을 우선합니다. 현 세션에 Lazyweb 조회도구가 없어 공급자 자료를 조회했다고 표시하지 않습니다.
