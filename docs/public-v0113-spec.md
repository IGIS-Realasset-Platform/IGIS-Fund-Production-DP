# v0.11.3 정식 주소 공개·가입 비밀번호 길이

기준일: 2026-10-19. 사용자는 정식 주소 공개를 승인했고, 회원가입 비밀번호를 8자 이상16자 미만으로 변경하도록 요청했습니다. 이는 진행 중인 배포의 추가 조건이며 기존 업무화면 재설계 요청이 아닙니다.

## 범위와 보존

- 공개주소: `https://igis-development-project-platform.vercel.app` (기존 Vercel 프로젝트에 verified alias 추가). 기존 `project-lqff8.vercel.app`은 정식주소로만 이동시킵니다.
- 기존 Preview 안정주소·과거 배포주소는 Vercel 보호를 유지합니다. 보호 전체를 끄지 않고 Standard Protection으로 정식 도메인만 공개합니다.
- 서버 지정12메일·최초 이메일6자리 소유확인·비밀번호해시·프로젝트별 권한·앱 전용 스키마를 유지합니다. 기존 회사 서비스/공유Auth/다른스키마/기존Secret값 변경·조회0입니다.
- 신규 가입/최초 비밀번호 설정은8~15자입니다. 과거 허용된12~128자 비밀번호의 로그인은 유지합니다. 로그인 입력검사는8~128자이며 저장된 해시는 변경하지 않습니다. 조합강제·자동trim·비밀번호재설정 기능을 새로 추가하지 않습니다.
- Preview와 Production은 동일한 앱 전용 계정/업무DB를 사용하되 서로 다른 host-only 쿠키와 Production용 별도 서명비밀로 로그인 세션을 분리합니다. 다른 호스트에서 최초 한 번 재로그인하는 것은 정상입니다. 기존Preview 비밀값은 변경하지 않습니다.
- 비밀값은 Vercel에 서버전용으로 저장합니다. Vercel API가 브랜치전용 Secret의 Preview+Production 겸용을 거부하므로, 기존 Gmail/DB/허용목록7개는 값 열람 없이 이 앱 프로젝트의 두 환경으로만 확장합니다. 승인브랜치 외 Git 자동빌드는 프로젝트의 Ignored Build Step으로 차단하고, 정식origin·서명비밀·승인화면지문은 Production에 별도로 설정합니다. 브랜치범위 메타데이터 변경과 Secret값 변경을 구분해 기록하며 다른프로젝트·Development에는 적용하지 않습니다.
