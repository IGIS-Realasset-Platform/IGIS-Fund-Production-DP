## 현재30일과 실제 변경 전·후

- 실제 모드는 한국시간 오늘을 포함한 최근30일, 즉 오늘-29일부터 오늘까지의 **공포일**로 조회합니다. 미래 공포일·잘못된 날짜·첫 관측일을 제외하고 시행일과 공포일을 섞지 않습니다. 자료 자체의 기준일은 유지하고, 샘플 모드의 원래 기준일 정책도 보존합니다.
- 국가법령정보센터가 제공하는 공식 신구대비표는 직접 연결합니다. 공식 자치법규 UI의 ‘법령비교’가 정확한 두 판본의 신구대비표를 제공하지 않는 사례는 실제 최종 화면까지 구분했습니다. 가짜 비교URL을 만들지 않습니다.
- 정확한 이전/개정 두 원문이 확인되면 `변경 전·후` 한 번으로 같은 창에 자동 조회하며, 문자가 실제로 다른 부분만 표시합니다. 이것을 공식 제공 신구대비표로 부르지 않습니다. 전체본문/부칙은 해당 범위 이름을 사용하고 개별 조문 비교인 척하지 않습니다.
- 실제 대조한 [서울특별시 건축 조례 개정 전 원문](https://www.law.go.kr/LSW/ordinInfoP.do?ordinSeq=2116749)은10083호·공포/시행2026-03-30, [개정 후 원문](https://www.law.go.kr/LSW/ordinInfoP.do?ordinSeq=2171799)은10170호·공포2026-10-01/시행2026-11-12입니다. 같은 공식ID2000120을 확인한 실제 두 원문입니다.
- 같은 이름만으로 동일 규정이라고 판단하지 않습니다. 대상종류·공식ID·판본순번·공포/시행일·번호·관할을 대조하고, 이전 판본이 모호하면 추측 선택하지 않습니다. 서버 응답·비교 후보·검색의 관리중/사업연결 판정까지 같은 ID 정의를 적용합니다.
- 강조는 양쪽 표시문자를 원문과 정확히 같게 보존하고 HTML을 이스케이프합니다. 긴 본문은 입력262144문자/누적 비교1000000셀의 상한을 두며 상한 초과 시 완전한 원문을 그대로 제공합니다. 과도한 계산이나 ‘모두 변경’ 표시로 대체하지 않습니다.
