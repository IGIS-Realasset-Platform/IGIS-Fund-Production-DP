## 1. 최신 요청과 대조 범위

사용자 최신 요청은 원사이트의 자료를 한 번 옮기는 데 그치지 않고, 제공 기능과 자동화를 플랫폼으로 이관하는 것입니다. 이전 CENTER120-03의 ‘원사이트 스냅샷 단방향 복구’ 범위만으로는 충족되지 않습니다.

- 원사이트: `https://raportal.vercel.app/03.%20Construction%20Board/index.html`.
- 원사이트 실제 UI·클라이언트 함수 관찰은 root가 담당했습니다. 이 문서 작성자가 중복 로그인하거나 원사이트에 저장하지 않았습니다.
- root는 16:56 KST 재확인에서 5개 순위표 각30행, 수주158건, 기사245건, 공식 코멘트11건, 확인 단가5건을 대조했다고 공유했습니다. 이것은 **자료 대조**이며 갱신 자동화 이관·신규 댓글 저장 검수와 별개입니다.
- 이 문서가 직접 읽은 정규화 검수자료의 수집시각은 `2026-10-20T05:05:57.907Z`입니다. 16:56 재확인을 이유로 원래 수집시각을 다시 쓰지 않습니다.
- 현재 코드: `src/partners.js`, `src/reference-data.js`, `scripts/normalize-portal-reference.mjs`, `server/center-services.mjs`, `server/cloud-storage.mjs`, `server/maintenance-runtime.mjs`, `vercel.json`, `src/spec.js`.
- 현재 동작의 제한된 실제 화면 근거: `.build/center120-product-browser/2026-10-20T07-16-12-723Z/evidence.json`의 격리 fullHTML 5분야150행·5상세·닫기·조회 무쓰기. 모의 API를 사용했으며 원격 기능 전수검수는 아닙니다.
- 원사이트의 서버 코드·예약 설정·원문 재수집 구현은 아직 이 문서의 독립 검토 범위에 없습니다. 브라우저에 `setInterval`이 없다는 관찰만으로 서버 자동화도 없다고 단정하지 않습니다.

## 4. 새 구현 전에 고정할 저장·권한 계약

아래는 구현 완료가 아니라 다음 합의/명세 항목입니다.

1. **원천 수집과 사용자 입력 분리:** 기준정보/수주/뉴스/단가/지표의 원문 버전은 사용자 댓글·협업·프로젝트 연결·영업기록과 별도 저장합니다. 갱신으로 입력자료를 덮지 않습니다.
2. **불변 식별값:** 원사이트 출처+업체 키, 발표버전/원행 키, 플랫폼 내부 회사ID를 분리합니다. 업체명·순위·같은 빈 등록번호로 병합하지 않습니다.
3. **댓글 추가 계약:** 현재 인증 작성자, 원래 생성시각, 본문, 협업 메타, 관련 projectId/미연결 원문, requestId를 구분합니다. 중복 저장/재시도·다른 사용자 동시 저장을 검사합니다. 편집·삭제는 원사이트 미확인 기능이므로 임의 추가하지 않습니다.
4. **최근 표시:** 원래 created_at에31일·미래제외 규칙을 적용합니다. 새로 수집한 과거 댓글을 최근으로 만들지 않습니다.
5. **내부연결의 명시 저장:** source 업체에서 입력할 때 source reference를 내부 기록에 명시 연결하는 최소 흐름이 필요합니다. 목록을 읽는 것만으로 회사150개를 생성하지 않습니다.
6. **회원/역할:** 기존12메일 가입, 앱 자체 세션, 프로젝트 권한을 유지합니다. 공식센터 글 게시자·온라인 댓글 독자/작성자·내부 연락처 독자 권한은 별도 합의합니다. 기존 직원의 자료/권한을 넓히거나 원사이트 Auth를 통합하지 않습니다.
7. **새 작은 API:** 댓글/협업/수집상태 변경에 전체 workspace PUT을 재사용할지 여부부터 재검토합니다. 특히 현재 companySalesLines 공용 제한·새 source 연결을 평범한 직원의 원가 저장과 함께 실패시키면 안 됩니다.
8. **자동화:** 원사이트에서 확인한 주기·자료원·이용조건·수집수단·부분실패를 근거로 새 서버 작업을 구현합니다. 수록값 조회·원문 링크·수동 DOM 변환을 정기 수집 완료로 표시하지 않습니다.
9. **분석 수치:** High/Medium/미확인/부적합, ㎡/평, 연면적/공급면적, 기본지수/세부4종/건축비/계약액을 구분합니다. 동일 원자료를 여러 번 합산하지 않습니다.
